# Guacamole

Guacamole est une application qui vous permet de prendre la main à distance à l aide des protocoles suivants : 

- RDP
- VNC
- SSH

Vous avez deux stacks disponibles : 

- MySQL
- PostgreSQL

Configuration en ligne : [https://rdr-it.com/docker-compose/#Guacamole](https://rdr-it.com/docker-compose/#Guacamole).
